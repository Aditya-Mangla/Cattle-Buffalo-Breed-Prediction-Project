# Breed Reader — Cattle & Buffalo Breed Recognition

**Convolutional Neural Network -based breed identification for Indian cattle and buffaloes**

Upload a photo, get the breed back in seconds — with confidence scores and top-3 alternatives, not just a single forced guess.


##  About

Breed Reader identifies indigenous cattle and buffalo breeds (Gir, Sahiwal, Murrah, and others) from a single photograph using a fine-tuned computer vision model. It's built around the SIH 2025 problem statement **"Image-based Breed Recognition for Cattle and Buffaloes of India"**, aligned with the **Bharat Pashudhan App** and **Rashtriya Gokul Mission** — helping field workers and farmers get fast, consistent breed identification without needing expert manual verification.

##  Features

- **Instant breed prediction** from a single uploaded photo
- **Top-3 alternatives with confidence scores** — surfaces uncertainty instead of hiding it, so low-confidence predictions can be flagged for manual review
- **Explainable predictions** via Grad-CAM visualizations, showing which part of the image (horns, hump, coat pattern) the model actually used
- **Reliable, reproducible training pipeline** — stratified train/val/test splits, class-imbalance handling, automated checkpointing, and dataset validation before training even starts
- **Drag-and-drop web tester** for quickly trying the model without a full frontend

##  Tech Stack

| Layer | Technology |
|---|---|
| Model | PyTorch + `torchvision` (EfficientNetV2-S, transfer learning) |
| Training | Jupyter Notebook, scikit-learn, Grad-CAM (custom hook-based implementation) |
| API | FastAPI + Uvicorn |
| Frontend (test UI) | Vanilla HTML/CSS/JS |

##  Getting Started

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Prepare your dataset
Arrange breed images as one folder per breed:
```
dataset/
├── Gir/
├── Sahiwal/
├── Murrah/
└── ...
```

### 3. Train the model
Run `project.ipynb` top to bottom. It validates the dataset, creates a stratified split, trains EfficientNetV2-S via transfer learning, evaluates on a held-out test set, and saves `cattle_breed_efficientnetv2s.pt` + `class_names.json`.

### 4. Run the API
```bash
python app.py
```
The API starts on `http://localhost:5000`, with interactive docs at `http://localhost:5000/docs`.

### 5. Try it out
Open `predict_test.html` in a browser and drop in a photo — or:
```bash
curl -X POST -F "file=@sample.jpg" http://localhost:5000/predict
```

## 🔌 API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | API and model status |
| `GET` | `/breeds` | List of recognizable breeds |
| `POST` | `/predict` | Upload an image (`file` field), get breed + confidence + top-3 |

**Example response:**
```json
{
  "breed": "Gir",
  "confidence": 0.94,
  "is_confident": true,
  "top_k": [
    { "breed": "Gir", "confidence": 0.94 },
    { "breed": "Sahiwal", "confidence": 0.04 },
    { "breed": "Kankrej", "confidence": 0.01 }
  ]
}
```

##  Model

- **Architecture:** EfficientNetV2-S, pretrained on ImageNet, fine-tuned in two stages (frozen-backbone head training, then partial unfreezing at a low learning rate)
- **Evaluation:** accuracy, top-3 accuracy, per-class precision/recall, and a confusion matrix on a held-out test set never seen during training or tuning
- **Explainability:** Grad-CAM heatmaps overlaid on predictions to visually verify the model is using the animal's actual features rather than background cues

##  Dataset

Trained on breed images sourced from public datasets including [ICAR-NBAGR](https://www.nbagr.res.in/)-aligned collections and Kaggle/Roboflow cattle-breed datasets. Dataset not included in this repository due to size — see notebook comments for suggested sources.
